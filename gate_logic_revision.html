Logic Gates & Truth Tables

A clean visual revision sheet — symbols, Boolean expressions, truth tables and exam shortcuts.

Core idea

A logic gate applies a Boolean operation to binary inputs and produces a binary output. 0 = LOW/FALSE; 1 = HIGH/TRUE.
For n independent binary inputs, the number of input combinations is 2ⁿ.
A small circle (bubble) on a gate symbol means inversion.

Fast memory rules

AND = all 1s · OR = any 1
XOR = different · XNOR = same
NAND = NOT(AND) · NOR = NOT(OR)

3. De Morgan’s theorems

(AB)̅ = Ā + B̅

Complement of AND = OR of complemented inputs.

(A + B)̅ = ĀB̅

Complement of OR = AND of complemented inputs.

Memory trick: Move the bar across the gate → AND ↔ OR, and complement every input.

4. Universal gates

NAND and NOR can each implement any Boolean function by themselves.

NAND-only conversions

NOT: Ā = A NAND A

AND: AB = (A NAND B) NAND (A NAND B)

OR: A + B = (A NAND A) NAND (B NAND B)

NOR-only conversions

NOT: Ā = A NOR A

OR: A + B = (A NOR B) NOR (A NOR B)

AND: AB = (A NOR A) NOR (B NOR B)

6. Truth-table problem method

  1. Count independent inputs, n.
  2. Make 2ⁿ input rows.
  3. Evaluate one gate at a time, from inputs toward the output.
  4. Compare the output column with known truth tables.
  5. Simplify the expression with Boolean algebra or K-maps if asked.
Example: Output sequence 1, 1, 1, 0 for inputs 00, 01, 10, 11 means NAND, so Y = (AB)̅.

7. Quick self-test

1. Which gate outputs 1 only for A = B = 1?

AND — Y = AB.

2. NOR output when A = 0 and B = 0?

1 — NOR complements OR.

3. XOR output for inputs 1, 1?

0 — the inputs are the same.

4. Which gates are universal?

NAND and NOR.

5. How many rows for 4 independent inputs?

2⁴ = 16 rows.

6. What does a bubble mean?

Logical inversion (NOT).
